# Arduino Assignments and Practice

This repository holds my work for the AEP Robotic Arms course (Aurora Educators Program). Everything is simulated in Tinkercad Circuits on an Arduino Uno.

## What I did

- Started with the basics: blinking an LED, controlling an LED with a button, and a three-light traffic light.
- **Actuators & Servo Motion:** built a 6-degree-of-freedom robot arm, with six servo motors each controlled by its own potentiometer (Assignment A).
- **Sensors:** worked with the HC-SR04 ultrasonic sensor, then built a distance alert system with a servo and a buzzer, found a weakness in its code and fixed it (Assignment B).
- **Final project:** an automatic dustbin lid that opens when a hand comes near, using an ultrasonic sensor and a servo, with LEDs and a hold-open button (Assignment C).
- **Capstone:** an autonomous and manual robotic arm simulation that combines servos, potentiometers, an ultrasonic sensor and a buzzer.
